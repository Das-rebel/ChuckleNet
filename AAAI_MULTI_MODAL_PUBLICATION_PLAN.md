# HISTORICAL / SUPERSEDED — AAAI 2027 Multi-Modal Publication Plan

**Original date:** 2026-04-04  
**Status:** HISTORICAL — RETAINED FOR PROVENANCE

> This document is preserved as part of the research history. It is not the current publication strategy.

## Why it is superseded

The original plan proposed a text/audio/visual biosemiotic laughter framework and included projected performance numbers such as 87.5% fusion quality before the required empirical validation existed. It also treated MELD `joy` as a laughter-related target and proposed Duchenne-laughter conclusions that the available labels cannot establish.

The current program rejects both assumptions.

## What survives

The useful ideas are retained in the current research spine:

- multimodal interaction is worth investigating;
- audio, visual behavior and temporal structure can be complementary;
- biosemiotics can provide a theoretical framing;
- conversational interaction should be studied as a sequence rather than isolated text.

## Publication sequence now

1. Robust acoustic interaction events.
2. Temporal interaction events and reaction timing.
3. Audio + vision interaction representation.
4. Incremental value beyond transcript semantics.

No paper should claim a result before the relevant experiment has actually been run and registered.
